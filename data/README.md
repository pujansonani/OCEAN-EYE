# OCEAN-EYE Dataset Directory Structure

This folder contains the offline synthetic and benchmark datasets for Incident `OCEAN-001`.

## Subdirectories:
- `satellite/`: Copernicus Sentinel-1 SAR imagery metadata and raster backscatter GeoTIFF references.
- `ais/`: Historical terrestrial and satellite AIS CSV/GeoJSON logs for the Arabian Sea / Mumbai High surveillance sector.
- `environment/`: INCOIS / ECMWF ocean current vectors (0.35 m/s @ 65°) and surface wind fields (6.2 m/s @ 240°).
- `incidents/`: Incident records, spill geometry polygons, and ground-truth validation cases.

All demonstration data is synthetically curated for SIH 2026 Round 2 evaluation.
